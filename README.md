# Jessi Todo 포장지

구글 Apps Script로 만든 할 일 앱(Jessi Todo)을 폰 홈 화면에 **진짜 앱처럼** 설치하기 위한 작은 페이지예요.

- 홈 화면 아이콘·이름: Jessi Todo (노란 아이콘)
- 주소창·'웹페이지' 표시 없이 앱 화면으로 열림
- 맨 위 'Apps Script 사용자가 만들었다' 줄이 안 보임

앱 자체(할 일·메모)는 구글 쪽에 있고, 앱 주인 계정으로 로그인해야만 열려요. 이 저장소에는 비밀 정보가 없어요.

## 설치 (삼성폰)
1. 크롬(또는 삼성 인터넷)에서 이 페이지 주소 열기
2. 메뉴 ⋮ → **홈 화면에 추가 / 앱 설치**
3. 옛 바로가기(G 아이콘)는 지우기
